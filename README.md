# Homepage www.edmundbruns.com

Dieses Archiv ist die Hauptablage der Homepage von Dr. Edmund Bruns.

- `site/` enthält die komplette Website, so wie sie online steht.
- `tools/` enthält die Bauwerkzeuge für die SOL-Module (Mathematik und Geschichte) und Prüfskripte.

## Veröffentlichung

Jede Änderung in `site/` auf dem Zweig `main` wird automatisch auf Cloudflare Pages (Projekt `bruns-homepage`) veröffentlicht. Der Ablauf steht in `.github/workflows/deploy.yml`. Ein manuelles Hochladen ist nicht mehr nötig.

Ältere Stände lassen sich jederzeit über die Versionsgeschichte zurückholen.
